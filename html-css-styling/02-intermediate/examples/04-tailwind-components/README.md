# Tailwind Components Demo

```bash
cd 02-intermediate/examples/04-tailwind-components
npm install
npm run dev
```

ไฟล์สำคัญ:

- `src/lib/cn.ts` — `clsx` + `tailwind-merge`
- `src/components/Button.tsx` — variants / sizes
- `src/components/Input.tsx` — label + error a11y
- `src/components/Modal.tsx` — dialog + Escape / backdrop
