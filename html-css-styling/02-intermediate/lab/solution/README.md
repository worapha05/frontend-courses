# เฉลย Lab Intermediate — Harbor UI

npm install
npm run sass
# เปิด marketing.html หลังได้ css/main.css

## App (Tailwind + React)

```bash
npm run dev
```

- `scss/` — 7-1 pattern
- `src/components/*` — Button / Input / Modal
- `src/lib/cn.ts` — clsx + tailwind-merge
- `NOTES.md` — คำตอบคำถามคิด
